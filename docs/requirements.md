# 初始运行与交付约定

依据：现有 `../../pre/赛题材料/` 中的提交模板和 2026 年 11 月 15 日版任务 PDF。本页记录工程约定，不能替代同学C后续复核的交付需求文档。

| 项目 | 约定 | 当前状态 |
| --- | --- | --- |
| 固定入口 | `run.sh`，接受 `--task`、`--test`、`--out-dir` | 参数入口已建立；研究执行尚未实现 |
| 运行基线 | Python 3.11、Linux、Docker | Dockerfile已准备；本机Python为3.12；容器待验证 |
| 输入 | `DATA_ROOT` 指向只读输入目录，JSON文件 | 自检只读取JSON并计算文件摘要 |

当前项目只建立通用反思与记忆研究所需的基础设施，不包含任何具体领域的决策算法或输出生成器。
