# 选型与下一阶段

## 已确定

- 执行层先采用原生 Python，保持轻量；用户已确认。
- 运行入口和配置沿用官方模板的参数与环境变量约定。
- 初始阶段只使用标准库，暂不引入智能体框架、数据库或外部服务。
- 算法设计和研究代码由队长负责。

## 仍待文献对齐

- 反思与记忆的具体研究问题、方法及其贡献边界。
- 记忆内容的表示、更新方式和持久化范围。
- 通用研究流程的输入、反馈与评价口径。
- 模型客户端的超时、重试和调用预算。

## 下一阶段顺序

1. 核对第一阶段文献总结、场景初案和交付需求文档的实际完成情况。
2. 确定通用研究方法与必要记录字段，把研究问题和验证依据写清楚。
3. 在配置确定后，单独接入官方模型网关并验证连通性。
4. 实现经讨论确定的研究方法，保留来源、版本、实验记录与人工复核结论。

如流程复杂度确实需要，再评估引入 LangGraph。其流程编排、状态和持久化能力参考[官方文档](https://docs.langchain.com/oss/python/langgraph/overview)；框架不替代反思方法设计。
