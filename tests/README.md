# 基础检查

在仓库根目录运行：

```bash
python -m unittest discover -s tests -v
```

当前检查：正常自检及输入不变、模型配置不泄露、损坏JSON的失败报告、未实现的研究执行明确失败，以及缺失输入和配置边界。

配置检查覆盖 TOML 相对路径、命令行／环境／文件优先级、空环境变量回退、非法或敏感配置拒绝，以及输出目录保护。

测试使用临时目录及虚构配置，不读取官方数据或调用模型。GitHub Actions 在 Python 3.11 的 Windows、Linux 环境执行相同测试。

研究方法确定后，再增加与研究贡献相关的必要测试。
